# Effect of high fat diet on the liver transcriptome - Microarray

Time-series data of the mouse liver transcriptome measured under normal
chow read using custom CDF file from Brainarray version 24.0.0 annotated
by Ensembl Gene ID followed by RMA normalization. The expression data
are in the log2 scale. The sample specification are present in the
column names in a `<group>`\_ZT`<time>` format.

## Usage

``` r
high_fat_diet_ma
```

## Format

An object of class `matrix` (inherits from `array`) with 23060 rows and
36 columns.
